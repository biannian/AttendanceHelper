下面按你这套 Scriptable 代码来配置。你需要做 **4 类东西**：

1. Scriptable 脚本  
2. 桌面小组件  
3. 手动刷新小组件的快捷指令  
4. 自动化提醒：到公司 / 离开公司 / 下午检查

---

# 一、Scriptable 里先准备脚本

## 1. 打开 Scriptable

新建一个脚本，名字建议叫：

```text
AttendanceHelper
```

把我给你的整段 JS 代码粘进去。

---

## 2. 修改代码顶部参数

至少改这几个：

```javascript
TOKEN: "你的 token",
DEVICE_ID: "你的 deviceid",
COMPANY_NAME: "光启",
SHORTCUT_NAME: "更新打卡小组件"
```

注意：

```javascript
TOKEN: "xxx"
```

这里不要写 `Bearer`。

错误：

```javascript
TOKEN: "Bearer eyJxxxx"
```

正确：

```javascript
TOKEN: "eyJxxxx"
```

因为代码里已经自动拼了：

```javascript
Authorization: `Bearer ${CONFIG.TOKEN}`
```

---

# 二、桌面小组件怎么设置

## 1. 添加 Scriptable 小组件

在 iPhone 桌面：

1. 长按桌面空白处
2. 点左上角 `+`
3. 搜索 `Scriptable`
4. 选择小组件尺寸

建议用：

```text
中号
```

中号信息最完整，也不容易挤爆。

---

## 2. 选择脚本

添加到桌面后：

1. 长按这个 Scriptable 小组件
2. 点 `编辑小组件`
3. Script 选择：

```text
AttendanceHelper
```

4. Parameter 填：

```text
widget
```

5. When Interacting 可以不用管，或者选择 Run Script

---

## 3. 小组件刷新逻辑

你的代码里有：

```javascript
widget.refreshAfterDate = getNextWidgetRefreshDate()
```

这只是告诉 iOS：建议几分钟后刷新。

但注意：**iOS 不保证准时刷新小组件**，所以我们还要加一个快捷指令：

```text
更新打卡小组件
```

用来手动或自动刷新。

---

# 三、快捷指令 1：更新打卡小组件

这个快捷指令名字必须和代码里的：

```javascript
SHORTCUT_NAME: "更新打卡小组件"
```

完全一致。

## 创建方式

打开 `快捷指令 App`：

1. 点右上角 `+`
2. 名称改成：

```text
更新打卡小组件
```

3. 添加动作，搜索：

```text
Scriptable
```

4. 选择：

```text
刷新所有小组件
```

如果你找不到这个动作，也可以用：

```text
Run Script
```

然后选择脚本：

```text
AttendanceHelper
```

参数填：

```text
widget
```

不过优先推荐：

```text
刷新所有小组件
```

---

## 这个快捷指令的用途

之后你点小组件时，会打开这个快捷指令刷新小组件。

因为代码里有：

```javascript
widget.url = getWidgetUrl()
```

点击小组件会运行：

```text
更新打卡小组件
```

---

# 四、快捷指令 2：离开公司检查打卡

这个用于你离开公司附近时自动判断：

- 今天有没有上班打卡
- 当前工时有没有满 9 小时
- 如果没满，提醒你还差多久
- 如果满了，提醒你可以下班并确认打卡

## 创建快捷指令

打开 `快捷指令 App`：

1. 点右上角 `+`
2. 名称改成：

```text
离开公司检查打卡
```

3. 添加动作，搜索：

```text
Scriptable
```

4. 选择：

```text
Run Script
```

5. Script 选择：

```text
AttendanceHelper
```

6. Parameter 填：

```text
leave
```

---

## 可以再加一个刷新动作

在 `Run Script` 后面再加：

```text
Scriptable：刷新所有小组件
```

这样离开公司检查后，小组件也会顺便更新。

最终动作顺序建议是：

```text
Run Script: AttendanceHelper, Parameter: leave
刷新所有小组件
```

---

# 五、自动化 1：离开公司时触发

这个自动化配合上面的 `离开公司检查打卡`。

## 创建自动化

打开 `快捷指令 App`：

1. 底部点 `自动化`
2. 点右上角 `+`
3. 选择：

```text
到达或离开
```

4. 选择：

```text
离开
```

5. 位置选择你的公司地址
6. 范围尽量调大一点，比如：

```text
100 米 - 300 米
```

如果公司附近定位飘，可以调到：

```text
500 米
```

7. 下一步
8. 添加动作：

```text
运行快捷指令
```

9. 选择：

```text
离开公司检查打卡
```

10. 关闭：

```text
运行前询问
```

如果系统允许，也关掉：

```text
运行时通知
```

---

## 注意

iOS 的位置自动化有时会要求确认，具体取决于系统版本。  
如果它不能完全静默执行，至少它会弹出通知，你点一下即可运行。

---

# 六、快捷指令 3：预约 9 小时提醒

这个用于每天上班后，根据你的实际上班打卡时间，预约一个提醒。

例如你 08:43 打卡，9 小时是 17:43。  
如果 `NEAR_MINUTES` 是 20，那么它会预约：

```text
17:23 快满 9 小时提醒
```

## 创建快捷指令

名称：

```text
预约9小时提醒
```

动作：

```text
Run Script
```

Script 选择：

```text
AttendanceHelper
```

Parameter 填：

```text
schedule9
```

后面也可以加：

```text
刷新所有小组件
```

最终建议：

```text
Run Script: AttendanceHelper, Parameter: schedule9
刷新所有小组件
```

---

# 七、自动化 2：到公司后预约 9 小时提醒

## 创建自动化

快捷指令 App：

1. 自动化
2. 右上角 `+`
3. 选择：

```text
到达或离开
```

4. 选择：

```text
到达
```

5. 位置选公司
6. 时间范围选择：

```text
任何时间
```

或者选你的上班时间段，比如：

```text
上午 7:00 - 上午 11:00
```

7. 下一步
8. 添加动作：

```text
运行快捷指令
```

9. 选择：

```text
预约9小时提醒
```

10. 关闭运行前询问

---

## 更稳的做法：用固定时间触发

位置自动化有时不够稳定，所以我更推荐你再加一个固定时间自动化。

例如你一般 9 点前打卡，可以设置：

```text
每天工作日 09:30
```

运行：

```text
预约9小时提醒
```

这样能保证即使到达公司自动化没触发，也会在 09:30 去读取一次上班打卡时间并预约提醒。

# 八、自动化 3：工作日下午兜底检查

这个是防止：

- 预约提醒失败
- iOS 没准时通知
- 小组件没刷新
- 你临时晚到，预约时间错过

它会检查是否快满 9 小时或已经满 9 小时。

## 创建快捷指令

名称：

```text
检查是否快满9小时
```

动作：

```text
Run Script
```

Script 选择：

```text
AttendanceHelper
```

Parameter 填：

```text
near9
```

后面加：

```text
刷新所有小组件
```

最终：

```text
Run Script: AttendanceHelper, Parameter: near9
刷新所有小组件
```

---

## 创建自动化

推荐建几个固定时间自动化，分别运行：

```text
检查是否快满9小时
```

建议时间：

```text
16:30
17:00
17:30
18:00
18:30
```

如果你上下班浮动大，可以加：

```text
19:00
```

每个自动化设置：

1. 自动化
2. `时间`
3. 选择具体时间，比如 `17:30`
4. 重复选择：

```text
每周
```

5. 勾选：

```text
周一、周二、周三、周四、周五
```

6. 下一步
7. 动作：运行快捷指令
8. 选择：

```text
检查是否快满9小时
```

9. 关闭运行前询问

---

# 九、推荐最终配置清单

你最终应该有这几个快捷指令：

| 名称 | 动作 | 用途 |
|---|---|---|
| 更新打卡小组件 | 刷新所有小组件 | 点击小组件刷新 |
| 离开公司检查打卡 | Run Script 参数 `leave` + 刷新小组件 | 离开公司时提醒 |
| 预约9小时提醒 | Run Script 参数 `schedule9` + 刷新小组件 | 根据上班时间预约提醒 |
| 检查是否快满9小时 | Run Script 参数 `near9` + 刷新小组件 | 下午兜底检查 |

自动化建议：

| 自动化 | 触发条件 | 运行快捷指令 |
|---|---|---|
| 到达公司 | 到达公司 | 预约9小时提醒 |
| 离开公司 | 离开公司 | 离开公司检查打卡 |
| 工作日 09:30 | 周一至周五 09:30 | 预约9小时提醒 |
| 工作日 16:30 | 周一至周五 16:30 | 检查是否快满9小时 |
| 工作日 17:00 | 周一至周五 17:00 | 检查是否快满9小时 |
| 工作日 17:30 | 周一至周五 17:30 | 检查是否快满9小时 |
| 工作日 18:00 | 周一至周五 18:00 | 检查是否快满9小时 |

# 十、最省事版本

如果你不想配太多，最低配这样就行：

## 快捷指令

1. `更新打卡小组件`
2. `离开公司检查打卡`
3. `预约9小时提醒`
4. `检查是否快满9小时`

## 自动化

只建 3 个：

1. 到达公司 → 运行 `预约9小时提醒`
2. 离开公司 → 运行 `离开公司检查打卡`
3. 工作日 17:30 → 运行 `检查是否快满9小时`

这个就够用了。
