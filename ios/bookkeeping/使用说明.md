# 截图记账第一版

## 安装脚本

1. 在 iPhone 安装 Scriptable。
2. 把同目录的 `记账.js` 传到手机（可使用 iCloud Drive 或其他文件传输方式）。
3. 在 Scriptable 新建脚本，命名为 `记账`，复制 `记账.js` 的全部内容并保存。
4. 先直接运行脚本，选择“手动记账”，录入一笔测试数据；再次运行选择“本月账本”查看。

## 创建快捷指令

1. 新建快捷指令，命名“截图记账”。
2. 在快捷指令详情开启“在共享表单中显示”，接收类型选择“图像”。
3. 添加“从图像中提取文本”（搜索“提取文本”），图像参数选择“快捷指令输入”。
4. 添加 Scriptable 的“运行脚本”动作，脚本选择“记账”。
5. 将该动作的 Parameter / 参数设置为上一步的“提取的文本”，不要传图片本身。
6. 如果动作里有“在 App 中运行 / Run in App”，开启它，便于显示确认表单。不同版本名称可能不同。
7. 保存后打开付款截图，点分享 → 截图记账；首次使用按系统提示授权。

若从快捷指令直接点击运行而没有分享图片，先增加“选择照片”动作，并把其结果接到 OCR 动作。第一版建议每次只分享一张截图。

## 验证识别

可临时将 OCR 动作换成“文本”，输入：

```text
淘宝
支付宝
付款成功
商品金额 ￥229.00
优惠 ￥30.00
实付款 ￥199.00
```

预期金额默认 199.00，购买渠道淘宝，支付账户支付宝。商户需手填，日期默认今天。再保存一次应出现疑似重复提醒；取消应不新增流水。

## 第一版范围

- OCR 由快捷指令完成，脚本仅接收文字；不调用付费 API。
- 金额优先匹配实付标签，再匹配货币符号。多个候选会显示，保存前必须核对。
- 支持人民币支出、退款、人工分类、手动记账、本月净支出及完整 JSON 导出。
- 商户需要手填，交易日期需要核对；尚不自动关联退款和原订单。
- 相同日期、金额、类型会提示疑似重复，不会自动删除或合并。
- 账本存放于本机 Scriptable 文档目录 `BookkeepingV1`，每笔一个 JSON；不会保存原图或 OCR 原文。
- 使用菜单“导出全部 JSON”备份到文件 App。卸载 Scriptable 前务必导出；第一版没有导入、编辑和删除界面。
- 此版不支持 iCloud 账本同步、外币、批量截图或后台自动读取各 App 交易。

## 验证状态

在电脑执行解析规则及模拟 Scriptable 流程检查；真实 iPhone OCR、共享表单、确认窗口和文件保存仍需手机实测。
